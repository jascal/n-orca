## Why

`mot_denoise_step` is n-orca's spec of a Cosmos-3-style Mixture-of-Transformers
(MoT) block, and its own description promises the two things that make MoT
work: the AR tower attends **causally over AR only**, and the DM tower attends
**bidirectionally over concat(AR, DM)**. The graph does neither:

- `dm_mha` (`DualStreamJointAttention`) has a single input, `dm_ln`. The AR
  stream never reaches the DM tower, so there is no joint attention at all:
  the "generator" is never conditioned on the "reasoner".
- The emitted PyTorch for both `DualStreamJointAttention` and the AR
  `MultiHeadAttention` is plain unmasked self-attention, so the AR tower is
  not causal. `mot_reasoner_only` makes the same causal claim and has the same
  gap.

This is the remaining *new change* follow-up from the archived
`add-cosmos-mot-world-models`.

## What Changes

- **`DualStreamJointAttention` becomes a two-input op**: `(dm, ar)` in
  `## flow` row order. Queries come from `dm`; keys and values come from
  `concat(ar, dm)` along the sequence axis, with no mask (DM is
  bidirectional). Output has `dm`'s shape. The shape rule checks that batch
  and feature dims match while the sequence lengths may differ.
- **`MultiHeadAttention` gains an opt-in `causal` 4th argument**:
  `MultiHeadAttention(d, h, dropout, causal)` emits a causal (upper-triangular)
  mask. The three-argument form is unchanged, so no existing document changes
  behaviour.
- **`mot_denoise_step`**: adds the `ar_ln → dm_mha` edge (AR keys/values feed
  the DM joint attention) and marks `ar_mha` causal. It declares `ar_tower` /
  `dm_tower` groups and `## properties` that make the MoT invariants
  checkable, including `unreachable: ar_out from dm_x_noisy` (no DM → AR
  backflow).
- **`mot_reasoner_only`**: marks its attention causal.
- Regenerate both `examples/cosmos-mot-*` pairs.
- **BREAKING (one-input documents):** a hand-written document that uses
  `DualStreamJointAttention` with one incoming edge no longer verifies. All
  shipped uses are generated by the builder.

## Capabilities

### New Capabilities
- `mot-joint-attention`: `DualStreamJointAttention`'s two-input shape rule and
  concat-K/V emission, the MoT builder wiring, and the checkable AR/DM
  invariants.
- `causal-self-attention`: `MultiHeadAttention`'s opt-in causal argument.

### Modified Capabilities
- None. The repo has no `openspec/specs/`; this supersedes the archived
  `add-cosmos-mot-world-models` statement that `DualStreamJointAttention` is
  topology-only.

## Impact

- `n_orca/ops/spec.py`, `n_orca/compiler/pytorch.py` (attention emission),
  `n_orca/world_models.py` (both MoT builders).
- `examples/cosmos-mot-denoise-step.*`, `examples/cosmos-mot-reasoner.*`. The
  denoise step leaves the frozen example baseline (it gains groups/properties,
  which the baseline forbids) and gets dedicated tests instead. The reasoner
  gains no groups, so it stays in the baseline with a regenerated entry (one
  Mermaid line gains `causal`). Every other baseline entry stays byte-identical.
- Parameter counts are unchanged: no weights are added or removed.
- Out of scope, recorded as a follow-up: the timestep embedding is computed but
  never injected into the DM path (`ts_embed → ts_out` only), which needs a
  broadcast add or adaLN op.
